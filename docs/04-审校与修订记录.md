# 审校与修订记录

2026年11月，本书在初版基础上做了一轮“子代理交叉审校 + 人工复核”的打磨。四个子代理分别负责事实核查、中文文字、PDF 版式和结构叙事；它们只提交问题清单，由我统一判断、修改、重排和复检。

## 一、结构上的四处调整

1. **把“四次押注”从序章口号变成全书骨架。** 序章改为“四次押注”，四部扉页各加一句押注定位；第13章的“四次押注，一个技术栈”增加“治理层”，并说明技术栈是“四层能力 + 一层治理”。
2. **第7、8章不再重复讲 ImageNet。** 第7章删去“李飞飞与 ImageNet”和“深蓝的遗产”两节，只保留“从深蓝到统计转向→数据→前夜→中国→2012 handoff”的线索；ImageNet 的完整故事交给第8章。
3. **第12→13章的接缝归位。** 删除第12章末尾只有一段话的“从回答到行动的代价”，把“智能体的代价”完整放在第13章开头；删除第13章重复的“聊天机器人说错话”段落。
4. **第9→10章的孤儿桥段删除。** 第9章不再保留“棋盘之外”的空泛总结，结束在中国坐标的“补链”运动；第10章从 2017 年 Transformer 干净开场。

## 五、仍然保留的取舍

- 2024—2026 年的部分仍是“快照”，不是最终历史；书中已用“据公开报道”“截至本书写作时”标注。
- 部分历史引文为中文翻译，不同版本措辞可能略有差异；书末“写作说明”已说明。
- 一些 P2 级版式建议（如每图正文回指、PDF /Lang、3mm 出血）未全部实施，因为不影响当前屏幕阅读版的质量。
- 最终 PDF 为 117 页；目录、页码与正文已重新核对。

这一轮修订的目标不是把书改长，而是让它更准确、更顺、更像一本可以送人的书。
