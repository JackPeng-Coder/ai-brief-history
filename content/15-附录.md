# 附录 C 术语表

| 术语 | 解释 |
|---|---|
| 人工智能（AI） | 让机器表现出类似人类智能行为的技术与研究领域，包括感知、推理、学习、语言、决策等。 |
| 机器学习 | 让计算机从数据中学习规律、而不必显式编程的方法。 |
| 监督学习 | 用带标签的数据训练模型，让模型学习输入到输出的映射。 |
| 无监督学习 | 在没有标签的数据中发现结构、模式或分组。 |
| 强化学习 | 智能体通过与环境互动、根据奖励信号调整策略的学习方法。 |
| 深度学习 | 使用多层神经网络进行表示学习的方法。 |
| 神经网络 | 由大量简单单元（神经元）连接而成的计算模型，通过调整连接权重来学习。 |
| 感知机 | 最早的单层神经网络分类器，由罗森布拉特提出。 |
| 反向传播 | 用链式法则计算神经网络中各层权重的梯度，并从输出层向输入层传播误差的训练算法。 |
| 卷积神经网络（CNN） | 用卷积核提取局部特征、适合处理图像和网格数据的神经网络。 |
| 循环神经网络（RNN） | 适合处理序列数据的神经网络，具有内部状态，可以记忆前面的输入。 |
| LSTM | 长短期记忆网络，用门控机制缓解 RNN 的梯度消失问题。 |
| Transformer | 2017年提出的基于自注意力的神经网络架构，是现代大语言模型的基础。 |
| 注意力机制 | 让模型根据相关性对不同位置的信息加权求和的方法。 |
| 自注意力 | Transformer 中让序列内每个位置与其他位置交互的机制。 |
| 大语言模型（LLM） | 在海量文本上预训练、参数量巨大的语言模型，如 GPT、Llama、Qwen。 |
| 预训练 | 在大规模无标注数据上训练模型，使其学习通用表示。 |
| 微调 | 在预训练模型的基础上，用特定任务的数据继续训练。 |
| 提示工程 | 通过设计输入提示来引导模型生成期望输出的方法。 |
| 思维链 | 让模型在给出答案前生成中间推理步骤的技术。 |
| RLHF | 基于人类反馈的强化学习，用人类偏好训练奖励模型，再用强化学习优化语言模型。 |
| 对齐 | 让 AI 系统的行为符合人类意图和价值观的研究与实践。 |
| 幻觉 | 模型生成看似合理、实际上错误或虚构的内容。 |
| 缩放定律 | 模型损失与参数量、数据量、计算量之间的幂律关系。 |
| 测试时计算 | 在推理阶段投入更多算力（如更长的思维链）来提升模型表现。 |
| 多模态 | 同时处理文本、图像、音频、视频等多种信息形式的能力。 |
| 生成式 AI | 能够生成文本、图像、音频、视频等内容的 AI 系统。 |
| 扩散模型 | 通过逐步去噪生成图像的生成模型，Stable Diffusion 等的基础。 |
| GAN | 生成对抗网络，由生成器和判别器互相对抗来生成逼真数据。 |
| 智能体（agent） | 能感知环境、制定计划、调用工具、执行任务以实现目标的 AI 系统。 |
| 具身智能 | 拥有物理身体、能在真实世界中感知和行动的智能系统。 |
| 世界模型 | 学习环境动态、能预测行动后果的内部模型。 |
| AGI | 通用人工智能，通常指在大多数认知任务上达到或超过人类水平的 AI。 |
| 符号主义 | 认为智能是对符号的规则操作、知识可以被显式表示的 AI 范式。 |
| 连接主义 | 认为智能从大量简单单元的连接中涌现、知识分布在权重中的 AI 范式。 |
| 专家系统 | 把领域专家的知识写成规则、在特定领域进行推理的系统。 |
| 知识图谱 | 用实体和关系表示知识的图结构数据库。 |
| 图灵测试 | 图灵提出的模仿游戏，用人类判断来评估机器是否能表现出智能。 |
| 中文房间 | 塞尔提出的思想实验，用来质疑机器是否真正“理解”语言。 |
| GPU | 图形处理器，因其并行计算能力成为深度学习训练的核心硬件。 |
| TPU | 张量处理器，Google 为机器学习定制的专用芯片。 |
| MoE | 混合专家架构，每次推理只激活部分专家，降低计算成本。 |
| 蒸馏 | 用大模型的输出训练小模型，把小模型的能力“压缩”出来。 |
| 上下文窗口 | 模型一次能处理的词元数量上限。 |
| 词元（Token） | 模型处理文本的基本单位，可能是词、子词或字符。 |
| 基准测试 | 用来评估模型能力的标准化任务集，如 MMLU、SWE-bench。 |
| 红队测试 | 让攻击者尝试诱导模型犯错或产生有害输出，以发现安全漏洞。 |
| RLVR | 用可验证奖励的强化学习：用规则或程序自动判断答案对错，训练推理模型。 |
| MCP | 模型上下文协议，让智能体用统一方式连接工具和数据源。 |
| VLA | 视觉—语言—动作模型，把图像、指令和机器人动作放进同一个模型。 |
| 可解释性 | 理解模型内部决策机制、解释其输出的研究。 |

# 附录 E 写作说明与致谢

## E.1 这是一本什么样的书

这是一本面向普通读者的 AI 简史，不是技术教科书，也不是投资指南。它试图回答三个问题：AI 从哪里来？它为什么一次又一次地热潮与寒冬？它正在把我们带向哪里？

本书的资料截至2026年11月。越靠近现在的部分，争议越大、变化越快。对2024年之后的事件，我尽量使用“据公开报道”“截至本书写作时”这样的表述，把事实、推测和判断分开。书中的数字，来自公开论文、机构报告和新闻报道；不同来源的口径可能不一致，我在正文中尽量注明。书中的引文，除特别注明外，均由笔者根据英文原文翻译；部分历史人物的原话，因年代久远，存在不同版本。

本书由 AI 辅助完成研究与写作，经人工审校、编辑和排版。AI 参与了资料整理、初稿生成、结构讨论和文字润色；最终的选题、结构、观点和错误，由编者负责。这是一次关于“AI 能否写书”的实验，也是一次关于“人如何与 AI 合作”的练习。它不完美，但它尽量诚实。

## E.2 方法与局限

写 AI 史，最大的困难不是资料太少，而是资料太多、太新、太偏。AI 是一个被资本、媒体、国家竞争高度关注的领域，很多“历史”在发生的当天就被写成了公关稿。本书尽量做到：

- 优先使用一手资料：论文、官方博客、机构报告、当事人回忆。
- 对争议事件，呈现不同说法，不急于下结论。
- 对预测性内容，保持怀疑；对“突破”“颠覆”“AGI”这样的词，保持克制。
- 把技术放在社会、经济、政治的语境里理解，而不是把技术当作自主的力量。

本书的局限也很明显：它覆盖全球，但以英文和中文资料为主；它涉及技术，但不可能深入每个算法的细节；它写到2026年，但2026年还没有结束。欢迎读者指出错误，提交问题或修改建议。
